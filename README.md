## 💻 Cara Menjalankan Secara Lokal

Pastikan Anda telah memiliki server lokal seperti **PHP CLI**, **Laragon**, **XAMPP**, atau ekstensi **Live Server**:

### 1. Menggunakan PHP Built-in Server
```bash
cd "portofolio v2"
php -S localhost:8088
```
Buka browser pada: `http://localhost:8088`

### 2. Menggunakan Laragon / XAMPP
Pastikan folder berada di direktori web root (contoh `C:\laragon\www\PORTOFOLIO Z AI V3\portofolio v2\`), lalu akses:
`http://localhost/PORTOFOLIO%20Z%20AI%20V3/portofolio%20v2/`
